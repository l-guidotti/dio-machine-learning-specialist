# Como registrar os estudos

## Após uma atividade

Abra o módulo, registre a data e escreva o conceito com suas palavras. Faça um pequeno experimento e documente o resultado observado. Use o template de anotação se precisar de mais estrutura.

## Ao implementar um projeto

Consulte o enunciado real, ajuste o roteiro e documente as dependências específicas. Separe dados e resultados; mantenha arquivos grandes fora do Git. Execute o notebook do início ao fim e substitua textos pendentes por resultados reais.

## Ao concluir

Atualize o checklist em docs/progresso.md e o estado na tabela do README principal. Registre a entrega e o commit. Os campos completed de docs/grade.json são uma representação inicial e devem ser atualizados manualmente se usados para acompanhar progresso.

## Antes de compartilhar

Revise saídas dos notebooks e arquivos para remover credenciais, dados pessoais e caminhos privados. Compartilhe apenas dados e materiais cuja licença permita redistribuição.
