# Grade da formação

Fonte: [DIO · Formação Machine Learning Specialist](https://web.dio.me/track/formacao-machine-learning-specialist). Consulta em 06/10/2026.

Informações exibidas: 92 horas, nível avançado, 51 cursos, sete desafios de projeto e um desafio de código. Os oito módulos somam 59 atividades. Os cartões somam 90 horas; o total divulgado pela formação foi preservado separadamente. A atividade de avaliação final aparece classificada como curso na página.

Pré-requisitos divulgados: conhecimentos básicos de lógica de programação e pensamento computacional. A DIO recomenda os três primeiros módulos, até programação orientada a objetos, da Formação Python Developer.
