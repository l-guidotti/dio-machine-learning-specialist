# Glossário rápido

| Termo | Significado |
|---|---|
| Feature | Variável ou representação usada como entrada. |
| Alvo / target | Resultado que o modelo supervisionado tenta prever. |
| Treino | Dados usados para ajustar parâmetros. |
| Validação | Dados usados para orientar decisões de configuração. |
| Teste | Dados reservados para avaliar a configuração final. |
| Baseline | Solução simples usada como referência de comparação. |
| Overfitting | Ajuste que captura particularidades do treino e generaliza mal. |
| Data leakage | Informação indisponível na previsão influenciando o treinamento ou a seleção. |
| Hiperparâmetro | Escolha de configuração do algoritmo ou treinamento. |
| Embedding | Representação vetorial de uma entrada. |
| Transfer learning | Aproveitamento de conhecimento de um modelo já treinado. |
| Fine-tuning | Ajuste adicional de parâmetros de um modelo previamente treinado. |
| Detecção | Localização e classificação de objetos. |
| Segmentação | Separação de regiões ou atribuição de classes aos pixels. |
| IoU | Interseção dividida pela união entre regiões. |
| mAP | Média de precisão média, com protocolo e limiares especificados. |

Definições autorais simplificadas para consulta durante os estudos.
