## Objetivo de estudo

Recuperar imagens semelhantes a uma imagem de consulta.

## Roteiro sugerido

Preparar catálogo; extrair vetores de características; normalizar quando adequado; calcular similaridades; retornar os itens mais próximos; inspecionar erros.

## Critério de avaliação sugerido

Precision@k ou avaliação de relevância documentada; tempo de consulta.

## Ponto de atenção
