## Objetivo de estudo

Classificar imagens reaproveitando representações de uma rede previamente treinada.

## Roteiro sugerido

Escolher uma base com origem e licença registradas; separar treino, validação e teste; congelar a base; treinar uma camada classificadora; avaliar antes de experimentar fine-tuning.

## Critério de avaliação sugerido

Acurácia, F1 por classe e matriz de confusão; comparar com um classificador simples.

## Ponto de atenção

Evitar imagens duplicadas entre partições e registrar quais camadas foram descongeladas.
