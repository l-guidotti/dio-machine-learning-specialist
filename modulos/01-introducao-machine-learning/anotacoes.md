# Anotações · Introdução ao Machine Learning

## Resumo conceitual inicial

Material autoral de apoio, organizado pelos temas dos títulos. Não é uma transcrição ou resumo de aulas assistidas.

Machine Learning usa exemplos para ajustar um modelo e produzir previsões ou representações. Em aprendizado supervisionado há um alvo conhecido; em aprendizado não supervisionado buscamos estrutura nos dados. Defina primeiro a tarefa: classificação prevê categorias, regressão prevê valores numéricos e agrupamento organiza exemplos por similaridade.

Uma rede neural combina camadas parametrizadas e funções de ativação. O treinamento ajusta os parâmetros para reduzir uma função de perda. Uma SVM busca uma fronteira de decisão com margem; kernels permitem trabalhar com separações mais complexas. Algoritmos genéticos exploram soluções por seleção, cruzamento e mutação.

O primeiro passo em um dataset é entender linhas, variáveis, alvo, valores ausentes e distribuição das classes. Uma boa pontuação nos dados usados para treinar não demonstra desempenho em dados novos.

**Prática sugerida:** escolha um problema cotidiano, defina entrada e saída e explique quais dados seriam necessários para avaliá-lo.
