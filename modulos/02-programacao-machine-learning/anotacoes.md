# Anotações · Programação para Machine Learning

## Resumo conceitual inicial

Material autoral de apoio, organizado pelos temas dos títulos. Não é uma transcrição ou resumo de aulas assistidas.

Python, R e Scilab permitem organizar dados e implementar experimentos. Mais importante que escolher uma linguagem é registrar etapas, dependências e critérios de avaliação. Separe leitura dos dados, transformação, treinamento e avaliação em funções com responsabilidades claras.

Ambientes virtuais isolam dependências. Um notebook ajuda a explorar ideias, mas deve funcionar quando executado do início ao fim, sem depender de células antigas fora de ordem. Ao usar Colab, registre as versões, a origem dos arquivos e se o experimento exige GPU.

Transfer learning aproveita representações de um modelo previamente treinado. Uma estratégia inicial é congelar a base e treinar uma nova camada de saída; ajustes posteriores devem ser comparados na validação.

**Prática sugerida:** rode os exemplos em [exemplos](../../exemplos/README.md) e registre o que cada entrada representa.
